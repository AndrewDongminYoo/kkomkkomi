The [spec](../specs/2026-10-31-production-build-provenance.md) and [plan](../plans/2026-10-31-production-build-provenance.md) define the build, review, merge and upload gates.

## Evidence boundary

This authoring stage records the preparation contract, not a completed artifact or store upload.
Measured source/hash, exported-version and signing evidence is added only after the declared clean builds pass.
Later store outcomes belong to an independently verified, surviving upload receipt; a prepared file alone does not establish processing or tester availability.

No public rollout, store app-review submission, tester/account change, backend deployment or device installation is included.
Play upload uses the internal track with explicit `draft` status, leaving tester distribution separate.
The bound listing/remote/assets for `1.1.1(5)` and their screenshot approvals are not regenerated by this binary preparation.
The listing/image guard must refuse a target mismatch until a separately scoped listing operation prepares new records.
Issue #40 remains open for any distribution/checklist requirement not actually verified.
